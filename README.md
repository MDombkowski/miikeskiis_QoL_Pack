# miikeskii's QoL Pack: the source

The source of **miikeskii's QoL Pack**, Valheim quality-of-life mods for BepInEx 5 and Jotunn, installed from Thunderstore as [miikeskiis QoL Pack](https://thunderstore.io/c/valheim/p/miikeskii/miikeskiis_QoL_Pack/). This is the source of its version 0.57.1; to play it, install it from Thunderstore.

- `QoLMods/`: the bundle (its plugin, the kit that runs each mod as a module, and the parts several mods share). `QoLMods/README.md` describes the pack, and `QoLMods/MODULES.md` says how to build it ("Building and packing the bundle").
- `AddToCart/`, `AFKRaidBlocker/`, `BarNone/`, `ComfortBuild/`, `CraftFromChests/`, `Grounded/`, `Handyman/`, `Hoarstone/`, `HouseTrained/`, `ItemStandIcons/`, `MapViewRules/`, `MapZoom/`, `MenUI/`, `NapTime/`, `Outfitter/`, `PortionControl/`, `PowerWheel/`, `QuickFix/`, `ReserveStock/`, `SpareKeys/`, `StoreStash/`, `Terraformer/`, `TopperUpper/`, `TraderCircles/`, `UseCase/`, `WorldSettings/`, `XPortalMapPicker/` and `ZFighter/`: each mod's own code, compiled into the bundle from there.
